# Super-Media-Library

一套跑在 Obsidian 里的个人媒体库：图书、电视剧、电影、动漫、游戏等作品都记成一页笔记，首页分类卡、导航页、数据表、进度与评分全部由 Dataview 驱动。

## 长什么样

- **首页** `媒体库/首页.md`：分类卡（图书 / 电视剧 / 电影 / 动漫 / 游戏 / 记忆宫殿）、继续观看、最近添加。
- **导航页** `媒体库/导航/`：全部作品、待体验、暂停中、回顾、搜索、数据健康，以及每种类型的分类页。
- **作品页**：状态 / 评分 / 收藏 / 进度（看到第几集）、开始与完成日期、关系（系列、合集、相关）、图库、体验记录（同一部作品看第几遍）。
- **数据表** `媒体库/视图/数据表/`：7 个 `.base` 视图。
- **新增作品**：QuickAdd 一键触发，按类型套用模板；或走豆瓣导入。
- **图库**：作品页底部，粘贴或导入的图片按「导入时间（精确到秒）+ 组名」自动成组，存 `媒体库/图库/<作品>/<时间 组名>/`。

## 目录结构

```
媒体库/
├── 首页.md              媒体库入口
├── 导航/                16 个分类页与列表页
├── 作品/                作品笔记（*.md）+ 封面/、横幅/
├── 图库/                <作品>/<导入时间 组名>/ 图片
├── 记录/                体验记录（第几次观看）
├── 模板/
│   ├── 手动/            9 种类型的手动新增模板
│   └── 豆瓣/            5 种类型的豆瓣导入模板
├── 视图/                14 组 dataviewjs 脚本（渲染逻辑）
├── 配置/                作品类型.json、豆瓣导入.json
└── 说明/                使用说明、数据字典、记忆宫殿
.obsidian/snippets/media-library.css   全部页面样式
```

## 需要的插件

全部通过「设置 → 第三方插件 → 浏览」安装。**加粗的是必需项**，其余按需。

| 插件 | 版本 | 作用 | 必需 |
| --- | --- | --- | --- |
| **Dataview**（`dataview`） | 0.5.68 | 所有页面的数据查询与渲染，缺了整库只有空页 | ✅ |
| **Meta Bind**（`obsidian-meta-bind-plugin`） | 1.5.1 | 作品页记录区的可写控件（状态下拉、评分、封面选择） | ✅ |
| **QuickAdd**（`quickadd`） | 2.33.1 | 「新增作品」多级菜单，套模板建笔记 | ✅ |
| Homepage（`homepage`） | 4.6.0 | 打开 vault 直接进媒体库首页 | 推荐 |
| **Douban**（`obsidian-douban-plugin`） | 2.5.0 | 从豆瓣抓元数据与封面 | ✅ |
| **Imagine**（`albus-imagine`） | 2.1.0 | 图片管理：浏览、去重、删除未引用图片 | ✅ |
| **Imagine 视图右键菜单**（`imagine-view-menu`） | 1.0.0 | 本库配套插件，给 Imagine 的视图加右键重命名/复制/删除 | ✅ |
| Claudian（`realclaudian`） | 2.3.38 | 在库内与 AI 对话 | 选用 |

Obsidian 版本要求 **≥ 1.13.1**（Meta Bind 的下限）。Imagine、Imagine 视图右键菜单、Claudian 仅支持桌面版。

## 安装

1. 把仓库克隆或下载解压成一个文件夹，用 Obsidian「打开文件夹作为库」指向它。
2. 按上表安装并启用插件。
3. 设置 → 外观 → CSS 代码片段 → 刷新并启用 `media-library.css`（文件已在 `.obsidian/snippets/`，没启用的话页面会很难看）。
4. 设置 → Homepage → 启动时打开 `媒体库/首页.md`。
5. **QuickAdd 要重建一次**：插件配置没有进仓库，需要在 QuickAdd 里重新建一个名为「新增作品」的 Multi 选择，下挂各类型模板。建完把新生成的 choice id 填进 `媒体库/视图/类型/view.js` 里对应类型的 `quickAddChoiceId`（文件顶部 `MEDIA_TYPE_DEFAULTS`，每个类型一个 id），否则首页的「新增」按钮找不到入口。
6. 豆瓣导入：装好 Douban 插件并登录，路径与字段映射见 `媒体库/配置/豆瓣导入.json`。

## 仓库里没有的东西

`.gitignore` 排除了以下内容，克隆下来需要自己补：

- **所有图片**：`媒体库/图库/`、`媒体库/作品/封面/`、`媒体库/作品/横幅/`，只剩 `.gitkeep` 占位。
- **插件本体**：`.obsidian/plugins/`，8 个插件约 8.7 MB。
- 工作区状态（`.obsidian/workspace.json`）、`.trash/`、Claudian 的会话记录。

## 改类型前先读这段

启用哪些类型由 `媒体库/配置/作品类型.json` 的 `enabled` 决定，类型的定义（标签、颜色、模板、路径）硬编码在 `媒体库/视图/类型/view.js` 的 `MEDIA_TYPE_DEFAULTS`。两处要一起改，并且必须把同文件的 `MEDIA_TYPE_CONTROLLER_VERSION` 加一，否则旧控制器会被缓存、界面不刷新。

## 约定

- 图片统一放 `媒体库/图库/`；作品 frontmatter 的 `gallery` 只是目录内容的镜像，真实数据以目录为准。
- 组名里的时间戳用 `-` 分隔时分秒（Obsidian 文件名不允许冒号），显示时再还原成 `:`。
- 状态改「待体验」会清空日期；改「进行中」写入开始日期，改「已完成」写入完成日期。
